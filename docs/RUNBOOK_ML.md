# ML run-book — everything Tanuj runs, in order

Everything here is free. Commands are for **Windows PowerShell** from the repository root (the folder that contains `ai/`, `backend/`, `docs/`). Replace `D:/civic` with any folder on your D drive.
After each step, paste the output (never a key) back to Claude. Steps marked **[you]** need your machine, accounts or language skills; nothing else is waiting on you.

## 0 · One-time setup

```powershell
git checkout tanuj; git pull
python -m venv .venv; .\.venv\Scripts\Activate.ps1
pip install -r backend/requirements.txt
pip install -e "ai[training,dev]"
pip install httpx onnx onnxruntime tokenizers
# only if you will train on your RTX 4050 (CUDA build of torch; check https://pytorch.org/get-started/locally for the exact line):
pip install torch --index-url https://download.pytorch.org/whl/cu121
pip install transformers ultralytics jupyter
```

### Preflight
```powershell
python -m ai.training.src.doctor
```
Lists what is installed (incl. whether torch sees your GPU), which keys / model ids / artifact paths are set (names only, never values) and what is still `MISSING`. Re-run it after each step.

### Where does `.env` go? (question 2)
In the **repository root**, next to `.env.example`:

```powershell
Copy-Item .env.example .env
notepad .env
```
Fill `GEMINI_API_KEY=` and `GROQ_API_KEY=` (no quotes, no spaces). `.env` is gitignored, so it is never committed. **Never paste a key into chat, GitHub or a notebook.** Real environment variables always win over `.env`. Editors that add a UTF-8 BOM or Windows line endings are handled. The gold CSV must be saved as **UTF-8** (Excel: *CSV UTF-8*), otherwise Devanagari text turns into `?`.

### Network access (question 3)
You do **not** need to open anything for the cloud session. Run the live checks on **your own laptop** (your keys stay local) and paste only the printed result. The only time the cloud session would need an allowlist entry is if you want Claude to call Gemini/Groq from there; that is not needed and not recommended.

## 1 · Find the model names (question 4) **[you]**

```powershell
python -m backend.ai_gateway.providers.live_check --list-models
```
It lists the model ids each key can use. Put them in `.env`:

| variable | what to pick | where |
|---|---|---|
| `AI_INTAKE_MODEL` | a Gemini **Flash** model (it must accept images and JSON-schema output) | Gemini list |
| `AI_ANALYTICS_MODEL` | a cheap Gemini Flash / Flash-Lite model (also the copilot) | Gemini list |
| `AI_TRANSCRIPTION_MODEL` | a **whisper-large-v3 / turbo** model | Groq list |
| `AI_EMBEDDING_MODEL` | leave empty (the local M7 embedder replaces it) | — |

Copy the id **exactly as printed**; never type one from memory (ids change). Then:

```powershell
python -m backend.ai_gateway.providers.live_check                       # text + JSON-schema check on every configured task
python -m backend.ai_gateway.providers.live_check --image some_pothole.jpg
python -m backend.ai_gateway.providers.live_check --audio clip.wav       # record 5 s in Marathi or Hindi (Voice Recorder -> wav/mp3)
```
Paste the output. This is the only proof that M1 (Gemini) and M2 (Groq Whisper) work live.

## 2 · Gold set (team-written test text) **[you]**

```powershell
python -m ai.training.src.text_corpus.build --gold-template D:/civic/gold.csv
```
Fill `text,language,label_id` with real-sounding complaints written **by you** (aim for ~100–200 per language, hi / mr / en / hi-Latn, spread over the 27 labels; see the template's example rows and `label_id` values). It is never trained on — it is the honest score of M6.

## 3 · Generate the training corpus (free LLM calls) **[you, ~hours of waiting]**

```powershell
python -m ai.training.src.text_corpus.generate --out D:/civic/shards --limit 40     # try 40 requests first
python -m ai.training.src.text_corpus.generate --out D:/civic/shards                # full run; re-run later if a free quota stops it
python -m ai.training.src.text_corpus.build --shards D:/civic/shards --out D:/civic/corpus --templates ai/artifacts/datasets/synthetic_v1 --gold D:/civic/gold.csv
```
`ai/artifacts/datasets/synthetic_v1` is regenerated by `python -m ai.training.src.build_dataset` if the folder lacks `train.jsonl`. Use `--backends en=groq,hi-Latn=groq,hi=gemini,mr=gemini` to split load across both free quotas. It is resumable: a quota stop just means "run the same command tomorrow".

## 4 · Notebook 07 — M6 classifier + M7 embedder **[you]**

Local (RTX 4050): `jupyter lab` → open `ai/training/notebooks/07_text_models_m6_m7_kaggle.ipynb` after setting
`$env:CIVIC_CORPUS_DIR="D:/civic/corpus"` in the same terminal. On Kaggle: upload `D:/civic/corpus` as a private Dataset, attach it, GPU on, Internet on.

1. `SMOKE = True` first (~5 min). Paste the last cells' output.
2. `SMOKE = False` for the real run. Default encoder `multilingual-e5-small` (batch 32). Stronger: `$env:CIVIC_TEXT_MODEL="intfloat/multilingual-e5-base"` and set `BATCH = 16` on 6 GB.
3. Unzip the bundle into `ai/artifacts/` so you get `ai/artifacts/civic_text_m6/<ver>` and `ai/artifacts/civic_embed_m7/<ver>`.

## 5 · Notebook 06 — road-damage detector (M5) **[you]**
Kaggle (recommended; overnight): the four datasets from notebook 05 attached, GPU on (T4 ×2 uses both GPUs; checklist and single-GPU switch in `docs/KAGGLE_RUNBOOK.md`), Internet on. `SMOKE = True` first (~10–15 min), paste output, then `SMOKE = False` + Save & Run All (Commit). Local alternative: set `CIVIC_PATHS_JSON` to the dataset folders and `CIVIC_YOLO_DEVICE=0`, batch ~16. Unzip the bundle so that `ai/artifacts/road_damage/road_damage/best.onnx` (with `model_card.json`) exists.

## 6 · Plug the models in

`.env`:
```
AI_TEXT_ONNX_PATH=ai/artifacts/civic_text_m6/<version>
AI_EMBED_ONNX_PATH=ai/artifacts/civic_embed_m7/<version>
AI_VISION_ONNX_PATH=ai/artifacts/road_damage/road_damage/best.onnx
```
Recalibrate duplicate fusion on the new embeddings, then point to the result:
```powershell
python -m ai.training.src.train_fusion_calibrator --data ai/artifacts/datasets/synthetic_v1 --out ai/artifacts/fusion_calibrator --semantic-mode local --embed-onnx ai/artifacts/civic_embed_m7/<version>
# then in .env:  AI_FUSION_EMBEDDING_WEIGHTS_PATH=ai/artifacts/fusion_calibrator/<new version>/fusion_weights.json
```

## 7 · Evaluate M6 with the same harness as B0
```powershell
python -m ai.evaluation.run_eval --task intake --system local --artifact ai/artifacts/civic_text_m6/<version>
```
(`--artifact` accepts either a B0 folder or an M6 ONNX folder.) Then run the API and try it:
```powershell
uvicorn backend.main:app --reload
```

## What each component gives you when finished

| | component | state today | done when |
|---|---|---|---|
| M1 | Gemini (intake / triage prose / copilot planner) | adapter + mock tests; **not live-checked** | step 1 output is green |
| M2 | Groq Whisper | same | `--audio` check prints a transcript |
| M3 | B0 char-n-gram fallback | trained (synthetic), weak (~0.62 category) | kept only as last fallback |
| M4 | fusion calibrator | trained on synthetic, lexical | recalibrated in step 6 |
| M5 | YOLOv8 road damage | pipeline proven on invented data; **not trained** | step 5 |
| M6 | fine-tuned e5 classifier | pipeline + export + backend runtime proven on a tiny model; **not trained** | steps 3–4 |
| M7 | e5 embedder | same | steps 3–4, 6 |
| M8 | browser Web Speech API | frontend (see `ai/INTEGRATION_HANDOFF.md` §16) | Krrish/Vedant |

Honest limits to keep in the demo story: M6/M7 train on LLM-written synthetic text (the gold set is the real yardstick); no free source of real Indian-language complaint narratives exists; AI never sets priority (deterministic rules do).
